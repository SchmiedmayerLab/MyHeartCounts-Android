# Public Signing Certificates

The public certificate for the My Heart Counts upload key may be stored here after the key is
generated. Public certificates and their SHA-1/SHA-256 fingerprints are not private key material.

Never store a keystore, private key, password, or Google service-account JSON in this directory.

The canonical certificate files are:

- `upload-certificate.pem`
- `upload-certificate-fingerprints.txt`
